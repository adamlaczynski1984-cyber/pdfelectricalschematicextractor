# PDF Electrical Schematic Extractor - Instrukcja Instalacji Windows\n\n## Wymagania\n- Windows 10 / Windows 11\n- Administrator access\n- ~2GB wolnego miejsca na dysku\n\n## Krok 1: Instalacja Python\n\n1. Pobierz Python 3.12.7:\n   https://www.python.org/downloads/release/python-3127/\n\n2. Kliknij na link `Windows installer (64-bit)`\n\n3. Uruchom instalator\n   - **WAŻNE**: Zaznacz checkbox `Add Python 3.12 to PATH`\n   - Kliknij `Install Now`\n   - Czekaj na zakończenie instalacji\n\n4. Sprawdź instalację - otwórz PowerShell (Win+X → Windows PowerShell) i wpisz:\n   ```powershell\n   python --version\n   ```\n   Powinno wyświetlić: `Python 3.12.7`\n\n---\n\n## Krok 2: Instalacja Tesseract OCR\n\n1. Pobierz Tesseract:\n   https://github.com/UB-Mannheim/tesseract/wiki\n   \n   lub bezpośrednio:\n   https://github.com/UB-Mannheim/tesseract/releases\n   \n   Pobierz: `tesseract-ocr-w64-setup-v5.x.x.exe` (najnowszą wersję)\n\n2. Uruchom instalator\n   - Zaakceptuj warunki\n   - Zaznacz wszystkie komponenty (jeśli pytany)\n   - Zainstaluj w domyślnej lokalizacji: `C:\\Program Files\\Tesseract-OCR`\n   - Kliknij `Install`\n\n3. Po instalacji, Tesseract powinien być automatycznie w PATH\n\n4. Sprawdzenie - otwórz PowerShell i wpisz:\n   ```powershell\n   tesseract --version\n   ```\n   Powinno wyświetlić informacje o wersji Tesseract\n\n---\n\n## Krok 3: Instalacja Poppler\n\n1. Pobierz Poppler dla Windows:\n   https://github.com/oschwartz10612/poppler-windows/releases\n   \n   Pobierz: `Release-XXX.zip` (najnowszą wersję)\n\n2. Rozpakuj ZIP na C:\\ tak aby powstał folder:\n   ```\n   C:\\poppler\n   ```\n\n3. Dodaj Poppler do PATH:\n   - Naciśnij `Win+X` i kliknij `System`\n   - Kliknij `Zaawansowane ustawienia systemu`\n   - Kliknij `Zmienne środowiskowe`\n   - Kliknij `Edytuj zmienną systemową PATH`\n   - Kliknij `Nowy` i dodaj:\n     ```\n     C:\\poppler\\Library\\bin\n     ```\n   - Kliknij `OK` na wszystkich oknach\n\n4. Otwórz nowe okno PowerShell i sprawdź:\n   ```powershell\n   pdftoppm -v\n   ```\n   Powinno wyświetlić wersję pdftoppm\n\n---\n\n## Krok 4: Pobranie Projektu\n\n1. Pobierz projekt z GitHub:\n   https://github.com/adamlaczynski1984-cyber/pdfelectricalschematicextractor\n   \n   Kliknij `<> Code` → `Download ZIP`\n\n2. Rozpakuj ZIP do wybranego folderu, np:\n   ```\n   C:\\Projects\\pdfelectricalschematicextractor\n   ```\n\n---\n\n## Krok 5: Instalacja Zależności Python\n\n1. Otwórz PowerShell\n\n2. Przejdź do folderu projektu:\n   ```powershell\n   cd C:\\Projects\\pdfelectricalschematicextractor\n   ```\n\n3. Utwórz wirtualne środowisko Python (venv):\n   ```powershell\n   python -m venv venv\n   ```\n\n4. Aktywuj venv:\n   ```powershell\n   .\\venv\\Scripts\\Activate.ps1\n   ```\n   \n   Powinna się pojawić nazwa `(venv)` na początku linii w PowerShell\n\n5. Zainstaluj zależności:\n   ```powershell\n   pip install --upgrade pip\n   pip install -r requirements.txt\n   ```\n   \n   Czekaj na zakończenie instalacji (może potrwać kilka minut)\n\n6. Sprawdzenie - spróbuj zaimportować biblioteki:\n   ```powershell\n   python -c \"import flask; import cv2; import pdf2image; print('OK')\"\n   ```\n   Powinno wyświetlić: `OK`\n\n---\n\n## Krok 6: Uruchomienie Aplikacji\n\n1. Upewnij się, że jesteś w folderze projektu z aktywnym venv:\n   ```powershell\n   cd C:\\Projects\\pdfelectricalschematicextractor\n   .\\venv\\Scripts\\Activate.ps1\n   ```\n\n2. Uruchom aplikację:\n   ```powershell\n   python app.py\n   ```\n   \n   Powinno się wyświetlić:\n   ```\n   Uruchamiam aplikację...\n    * Running on http://127.0.0.1:5000\n   ```\n\n3. Otwórz przeglądarkę i wejdź na:\n   ```\n   http://localhost:5000\n   ```\n   \n   Aplikacja powinna się załadować 🎉\n\n---\n\n## Krok 7: Utwórz Skrót na Pulpicie (opcjonalnie)\n\n1. Utwórz plik `run.bat` w folderze projektu (już powinien być)\n   \n   Zawartość:\n   ```batch\n   @echo off\n   cd /d \"%~dp0\"\n   .\\venv\\Scripts\\python.exe app.py\n   if errorlevel 1 (\n       echo.\n       echo Blad uruchamiania aplikacji.\n       pause\n   )\n   ```\n\n2. Kliknij prawym przyciskiem na `run.bat` → `Wyślij do` → `Pulpit (skrót)`\n\n3. Od teraz możesz kliknąć na skrót na pulpicie, aby uruchomić aplikację\n\n---\n\n## Troubleshooting\n\n### \"Python nie rozpoznawany\" / \"'python' is not recognized\"\n- Sprawdź, czy Python jest w PATH\n- Uruchom instalator Python ponownie i zaznacz `Add Python to PATH`\n- Zrestartuj komputer\n\n### \"Tesseract is not installed\" / OCR nie działa\n- Sprawdź czy Tesseract jest zainstalowany w `C:\\Program Files\\Tesseract-OCR`\n- Jeśli nie - zainstaluj go ponownie\n- Zrestartuj PowerShell aby załadować PATH\n\n### \"Unable to get page count\" / PDF się nie otwiera\n- Upewnij się, że Poppler jest zainstalowany w `C:\\poppler`\n- Sprawdź czy `C:\\poppler\\Library\\bin` jest w PATH\n- Zrestartuj PowerShell\n\n### \"ModuleNotFoundError\" podczas instalacji bibliotek\n- Upewnij się, że venv jest aktywny `(venv)` powinno być widoczne\n- Spróbuj:\n  ```powershell\n  pip install --upgrade pip setuptools wheel\n  pip install -r requirements.txt\n  ```\n\n### Aplikacja uruchomia się ale nic się nie wyświetla\n- Otwórz przeglądarkę\n- Wejdź na `http://localhost:5000`\n- Jeśli nic się nie pojawiło, sprawdź czy port 5000 nie jest zajęty\n- Spróbuj innego portu w `app.py`: zmień `port=5000` na `port=5001`\n\n---\n\n## Aktualizacja Projektu\n\nAby pobrać najnowszą wersję:\n\n1. Otwórz PowerShell w folderze projektu\n\n2. Aktywuj venv:\n   ```powershell\n   .\\venv\\Scripts\\Activate.ps1\n   ```\n\n3. Zaktualizuj zależności:\n   ```powershell\n   pip install -r requirements.txt --upgrade\n   ```\n\n4. Uruchom aplikację:\n   ```powershell\n   python app.py\n   ```\n\n---\n\n## Wsparcie\n\nJeśli masz problemy:\n1. Sprawdź Troubleshooting powyżej\n2. Otwórz PowerShell i uruchom aplikację, aby zobaczyć dokładny komunikat błędu\n3. Skontaktuj się z twórcą projektu na GitHub\n\n---\n\n**Aplikacja powinna być gotowa do pracy! 🎉**\n"
